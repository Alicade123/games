How to Play

A number will appear for 2 seconds.

Remember that number.

After 2 seconds, the number will disappear and a new number will appear.

Calculate the difference between the number you saw and the current number then type the difference.

Difficulty

  • Easy: 0–9 — answer is checked automatically.
  • Medium: 0–100 — use Check button or Enter.
  • Hard: 0–1000 — use Check button or Enter.

Game Over

In Time Limit mode, the game ends when the timer reaches zero.

In Time Limit mode, a wrong answer does not end the game.

In No Time Limit mode, a wrong answer ends the game immediately.
